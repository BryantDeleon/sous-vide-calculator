# Sous Vide Time and Temperature Calculator

A free sous vide calculator by [OWKAR](https://owkar.com/). One static page, no build step needed to host it.

## Publish on GitHub Pages

1. Create a new public repository, for example `sous-vide-calculator`.
2. Upload every file in this folder to the root of the repository, including the hidden `.nojekyll` file.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://bryantdeleon.github.io/sous-vide-calculator/`.

## Before you publish

The page's canonical URL, share image URL, sitemap, robots.txt and embed code all point to the live address. If the address above doesn't match your final one, replace every `https://YOUR-GITHUB-USERNAME.github.io/sous-vide-calculator/` in `index.html`, `robots.txt` and `sitemap.xml` with your real address (ending in `/`).

## Custom domain (optional)

To use something like `tools.owkar.com`, add the domain under **Settings → Pages → Custom domain**, create a CNAME DNS record pointing to `BryantDeleon.github.io`, and tick **Enforce HTTPS**. Then update the addresses as described above.

## After it's live

- Submit `sitemap.xml` in Google Search Console.
- Test the share card with a link preview tool, since the share image uses an absolute URL.
